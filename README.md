# ProdTab

ProdTab is a lightweight new tab / startpage extension for Firefox, built with plain HTML, CSS, and JavaScript.

https://github.com/user-attachments/assets/73f0ba5b-c89c-405a-8453-f13f7d679eb3

It focuses on a clean daily dashboard with:

- Personalized onboarding (name + optional city)
- Time-based greeting, with a 12- or 24-hour clock
- Dynamic weather and background effects for your city, in Celsius, Fahrenheit or Kelvin
- Search box that opens addresses directly and searches with your choice of engine (including Firefox's default)
- Up to 12 bookmark cards: add, edit, delete (with undo) and reorder by dragging
- Automatic, system, light or dark theme

## Installation

1. Install from the Firefox Add-ons store (recommended):
   - https://addons.mozilla.org/en-US/firefox/addon/prodtab
2. Or load it manually:
   - Open `about:debugging#/runtime/this-firefox`
   - Click **Load Temporary Add-on...**
   - Select the `manifest.json` file from this project

### Use the hosted copy as your homepage

1. Open `about:preferences#home`.
2. Under **Homepage and new windows**, choose **Custom URLs...**.
3. Enter `https://prodtab.vercel.app`.

## Privacy

Your name, city, bookmarks and preferences are stored only in your browser (`localStorage`). There is no ProdTab server and no analytics. ProdTab does contact these services:

- **[Open-Meteo](https://open-meteo.com/)**: your city name, to find its coordinates, and those coordinates, to get the current weather. Nothing is sent if you leave the city empty.
- **Your bookmarked sites**: each bookmark's icon is loaded from that site's own `/favicon.ico`, with no referrer.
- **Your search engine**: whatever you type and press Enter on, exactly as if you had searched from the address bar.

Fonts are bundled with the extension, so nothing is loaded from Google Fonts.

## Development

You need [Node.js](https://nodejs.org/) 22 or newer and Firefox.

```sh
npm install
npm start          # opens Firefox with ProdTab loaded; reloads on changes
npm test           # unit tests (node:test)
npm run lint       # ESLint + Mozilla's add-on linter
npm run format     # Prettier
npm run check      # format check + lint + tests
npm run package    # builds the .zip for addons.mozilla.org into web-ext-artifacts/
```

The page uses ES modules, which browsers don't load from `file://` URLs. To try the hosted (non-extension) version locally, serve the folder instead of opening `index.html` directly, for example with `npx serve .`.

### Project layout

- `index.html`, `assets/style.css`: the page
- `assets/js/main.js`: startup; connects the modules below
- `assets/js/`: one module per feature (`bookmarks`, `weather`, `search`, `settings`, `theme`, `effects`, ...). Modules without DOM access (`url`, `search`, `data`, `weather`, `holidays`, `clock`) are covered by the tests in `tests/`.
- `assets/js/tlds.js`: list of real top-level domains, generated by `npm run update-tlds`
- `assets/fonts/`: Plus Jakarta Sans, JetBrains Mono and Lora (SIL Open Font License)
